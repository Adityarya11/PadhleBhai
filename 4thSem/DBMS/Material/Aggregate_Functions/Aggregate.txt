COUNT
****************************************************************
SELECT COUNT(*) FROM aggrtable;   
SELECT COUNT(ALL *) FROM aggrtable;

SELECT COUNT(DISTINCT *) from aggrtable; This syntax is not correct we need to specifically tell the colums where distinct rows are needed.
Invalid


SELECT COUNT(A) FROM aggrtable;
SELECT COUNT(ALL A) FROM aggrtable;
6
SELECT COUNT(DISTINCT A) FROM aggrtable;
4


SELECT COUNT(B) FROM aggrtable;
SELECT COUNT(ALL B) FROM aggrtable;
SELECT COUNT(DISTINCT B) FROM aggrtable;
0


COUNT(*) counts all rows (including those with NULL values), 
COUNT(column_name) counts non-NULL values in a specific column, and
COUNT(DISTINCT column_name) counts distinct non-NULL values.

SUM: The SUM function returns the total sum of a numeric column.
SUM(column_name) adds up non-NULL values in a specific column, and 
SUM(DISTINCT column_name) adds up distinct non-NULL values.
