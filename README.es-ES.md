

# StudyMaterials 

Este es el archivo de los materiales del curso que he reunido desde el cuarto semestre hasta ahora. 

### Cómo usar
Abre la url 

### Cómo añadir un material 
- clona el repo 
- añade el material a la ruta específica
- ejecuta `normalize_filenames.py`
- ejecuta el script `generate_site.py`
- guarda el archivo html.
- realiza push de los cambios

Tus archivos se verán en el sitio web en breve 

### Por qué lo hice 
Para facilitar el acceso a los materiales a través de un sitio web desde cualquier lugar y en cualquier momento.


### Cómo funciona
- `index.html` es una página web estática automatizada generada mediante `generate_site.py` (¿quién escribiría todo el html a mano?) 
- ejecútalo cada vez que se añada un nuevo material 
- el script generará la lista de los materiales y se actualizará a sí mismo
- Listo.
